IAN.md: My personal AI use guidelines

My AI use policy for my personal endeavors.
Last Updated: 8/8/2026.

General Guidelines
  • Content generated by an LLM can only ever have utilitarian value and never personal or artistic value.
  • If it can be reasonably assumed that a task will offer no artistic, personal, or substantial educational value, it is acceptable to automate it with an LLM.
  • Never accept AI output that you are not able to fully understand.
  • Never give a prompt to an LLM that you would not show to Sam Altman.
AI Coding Guidelines
  • Never use an AI coding agent to write code for a game or educational project.
  • Never copy and paste code from an LLM into a game or educational project.
  • Never copy and paste code from a game or educational project into an LLM.
  • Any code written by an LLM that is made public must be labeled as such.
Planning and Research Guidelines
  • Never use an LLM to brainstorm for artistic projects.
  • It is acceptable to use LLMs to find, summarize, and explain information.
